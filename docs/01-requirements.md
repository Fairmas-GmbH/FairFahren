# 01 — Requirements

**Project:** FairFahren — procedural Berlin taxi driving simulation
**Purpose:** Prepared base project for developer interviews. Candidates extend it.
**Status:** MVP (v0.1.0)

## 1. Vision

A small 3D driving game in the browser: you steer a German taxi (light ivory, yellow "TAXI" roof sign) through a part of Berlin. Everything you see is **generated by code from a single seed**: no textures, no 3D models, no audio files. The whole game ships in **kilobytes, not megabytes**.

The project is intentionally small, readable and dependency-free, so a candidate can understand it in 30–45 minutes and then extend it.

## 2. Stakeholders

| Role | Interest |
|---|---|
| Hiring team / interviewers | A realistic, engaging task that reveals engineering skill: reading unfamiliar code, design, maths, performance, testing, communication. |
| Candidates | A fun, self-contained codebase that runs with zero setup friction. |
| Maintainers of the task | Easy to adjust difficulty, add new tasks, keep the reference solution in sync. |

## 3. Functional requirements (MVP)

| ID | Requirement | Acceptance criteria |
|---|---|---|
| FR-01 | The game runs in a desktop browser from a static web server. | `npm start`, open `http://localhost:8080`, the city and taxi appear within 1 s. |
| FR-02 | The player drives a taxi with **W/A/S/D** or the **arrow keys**. | W/↑ accelerates, S/↓ brakes then reverses, A/← and D/→ steer. Works on QWERTY and QWERTZ. |
| FR-03 | Handbrake, reset, camera and sensor view. | Space = handbrake, R = back to spawn, C cycles chase / bonnet / overhead camera, V toggles the sensor view. |
| FR-04 | The taxi looks like a German taxi. | Ivory saloon (RAL 1015 "Hellelfenbein"), yellow roof sign reading "TAXI" from front and back, turning and steering wheels. |
| FR-05 | The world is a procedurally generated part of Berlin. | Street grid with Berlin street names; perimeter blocks of pre-war buildings (*Altbau*) with courtyards; prefab panel buildings (*Plattenbau*), more of them to the east; parks; the river Spree with bridges; a boulevard "Unter den Linden" with linden trees; a city gate on the boulevard; a TV tower on a plaza. |
| FR-06 | The city is deterministic and seedable. | Same seed → identical city. `?seed=<int>` in the URL selects a different city. Default seed 1989. |
| FR-07 | The taxi collides with the world. | Cannot drive through buildings/curbs, gate pillars, river (except via bridges), or past the city border. Impacts bounce and slow the car. |
| FR-08 | HUD | Speed in km/h, current street name (or "A / B" on crossings, "… · Spreebrücke" on bridges), seed, FPS, camera mode, key help. |
| FR-09 | Traffic signs in the city. | German signs on the right-hand sidewalk: speed limits 30/50 after crossings (per-street limit, Tempo-30 zones on side streets), priority-road signs along the boulevard, yield signs where side streets meet it. |
| FR-10 | **Sensor view** — the environment "as the car sees it" (driver-assistance display). | HUD panel (toggle **V**), top-down and car-up: road edges/curbs, river, lane markings, detected objects (trees), 360° lidar returns, park-sensor bars with distance (green/amber/red), forward radar distance, recognised traffic signs with distance, active speed limit with speeding highlight, collision warning when time-to-collision < 1.6 s. Zooms in when slow, out when fast. |
| FR-11 | **Street life.** | Pedestrians (some with dogs) walk the sidewalks, pigeons flee the taxi, bird flocks circle, swans and ducks swim on the Spree, trees sway in the wind, UFOs hover (one around the TV tower), planes pass low and high, and flying time-travel cars flash in and out over the streets. All seeded and deterministic; see `docs/plans/street-life.md`. |

## 4. Non-functional requirements

| ID | Requirement | Measure |
|---|---|---|
| NFR-01 | **Size budget.** Shipped game (`index.html` + `src/**`) stays tiny. | ≤ 160 KB raw **and** ≤ 52 KB gzip, checked by `npm run size` (exit code 1 if exceeded). Base game: ~116 KB raw / ~41 KB gzip. |
| NFR-02 | **Fully procedural.** No binary or data assets. | No images, models, fonts, audio, JSON level files. Everything derived from code + seed. |
| NFR-03 | **Zero dependencies.** | No runtime or dev npm dependencies; no CDN scripts. Node is only needed for the dev server, tests and size check. |
| NFR-04 | **Performance.** | 60 FPS on a mid-range laptop with integrated GPU at 1080p. City = one draw call. Generation < 50 ms. |
| NFR-05 | **Determinism.** | World generation uses only the seeded RNG (never `Math.random()`); physics runs at a fixed 120 Hz step. |
| NFR-06 | **Testability.** | World generation, physics and collision are pure modules (no DOM/WebGL) with unit tests (`npm test`). |
| NFR-07 | **Readability.** | Plain modern JavaScript (ES2022 modules), no build step, short files with a header comment explaining purpose. |
| NFR-08 | **Browser support.** | Current Chrome, Edge, Firefox, Safari with WebGL2. Clear error message if WebGL2 is missing. |

## 5. Out of scope for the MVP

These are deliberately left out and are good candidate tasks (see [04-candidate-brief.md](04-candidate-brief.md)):
passengers / fares / game loop, traffic & pedestrians, traffic lights, minimap, sound, day/night, shadows, mobile/touch/gamepad controls, infinite or streamed city, damage, save games, multiplayer races over the intranet (task G).

## 6. Constraints and assumptions

- Must run offline after checkout — no network access needed.
- Interview sessions are 2–4 h (take-home) or 60–90 min (live pairing); tasks are sized accordingly.
- Berlin is represented by recognisable *character* (block structure, river, boulevard, landmarks, names), not by an accurate map.
- Landmarks are generic stylised shapes, not reproductions of copyrighted designs.

## 7. Glossary

| Term | Meaning |
|---|---|
| Altbau | Pre-1918 Berlin tenement building, 4–6 floors, tall windows, shops on the ground floor. |
| Berliner Block | Large urban block with perimeter buildings around inner courtyards (*Hinterhöfe*). |
| Plattenbau | Prefab concrete-panel housing (GDR era), 8–11 floors. |
| Baulücke | Vacant lot in an otherwise closed row of buildings. |
| Ufer | Riverside street ("bank"), e.g. *Reichpietschufer*. |
| Seed | 32-bit integer from which the entire world is derived. |
